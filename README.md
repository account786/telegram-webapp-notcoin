# Telegram Web App - Not Coin System

## Features
- User dashboard: Not Coin balance, daily ad progress
- Daily ad task: 30 ads/day, 100 coins randomly distributed
- Referral system (example)
- Daily bonus: Claim once every 24 hours
- Mobile-friendly for Telegram Web Apps

## Setup
1. Create MySQL database
2. Rename `config.example.php` → `config.php` and add DB credentials
3. Upload files to your server
4. Open `index.php` in Telegram Web App
